# 10 客户端端到端压测

**Blocked by**: T12, T13, T15

## 目标
验证 10 个 H5 客户端同时串流的完整场景：同时连接、视频/音频广播、控制权切换、客户端断网恢复、房间满拒绝。

## 涉及层
- [ ] 测试：10 个浏览器标签页同时连接同一房间
- [ ] 测试：全部收到视频流，画质相同
- [ ] 测试：1 个客户端断网 → 其余 9 个不受影响，码率可能上升（min 值变大）
- [ ] 测试：控制权排队切换（A → B → C → A 循环）
- [ ] 测试：控制者断网 → 控制权自动转移
- [ ] 测试：第 11 个客户端尝试连接 → 被拒绝（房间满）
- [ ] 性能：监控云机 CPU/内存，确认 10 路 PeerConnection 的资源开销可接受

## 验收标准
- 10 个 H5 客户端全部流畅串流，无明显卡顿（帧率 > 24fps）
- 控制权切换延迟 < 500ms（从释放到下一个获得）
- 客户端断网后其余客户端恢复时间 < 3 秒（码率回升）
- 第 11 个客户端收到明确的"房间已满"错误
- 云机 CPU 占用 < 80%，内存增长稳定（无泄漏）
- 持续运行 30 分钟无崩溃
